工事かんたん請求（テスト版）

## このリポジトリについて
- このリポジトリはテスト専用です。本番環境・本番リポジトリ・本番URLではありません。
- 作業対象は main ブランチです。
- 本番環境には変更を加えないでください。

## 現在の仕様
- 工事データは端末内に暗号化して保存します。
- 暗号化バックアップの書き出し・読み込みに対応します。
- バックアップはアプリのロック解除パスワードで暗号化し、専用パスワードは設けません。
- 旧形式の暗号化バックアップ（KOUJI-KBACKUP-1）も復元に対応します。
- バックアップ復元後は、暗号化保存データを復号して復元対象データと再照合してから完了表示します。
- 30分間無操作で自動ロックします。
- 請求書・見積書・領収書のPDF作成とファイル保存に対応します。
- PDFの自動プレビューは行いません。
- 領収書は入金済みの工事に対して発行します。
- 工事履歴は自動削除しません。
- Dropbox同期機能はありません。

## アイコン
- PWAアイコンは icon.svg を使用します。
- manifest.webmanifest と service-worker.js に登録しています。
- PNG形式の192×192・512×512アイコンは現時点では含みません。

## テスト時の注意
- 実機テストでは、実データを誤って入金済みにしたり、復元で上書きしたりしないよう、テスト用データ・バックアップを使用してください。
- バックアップのパスワードは忘れないよう安全な場所に保管してください。
- 本番環境への反映は、別途確認・承認を得てから行ってください。


パスワード移行時は、設定情報・暗号化データの保存と旧データ削除を読み戻し確認し、失敗時は変更前の各データを差し戻して再確認します。

ログイン開始時は、一時ログイン鍵の保存が成功してからロック画面を閉じます。保存に失敗した場合はロック画面を表示したままにし、再試行できるようにします。

初回パスワード登録時も、パスワード情報の保存後に読み戻し確認を行い、失敗時は変更前の設定へ差し戻して確認します。

一時ログイン状態の保存では、ログイン時刻の保存に失敗した場合に一時ログイン鍵を消去します。ログアウト・自動ロック時の消去は、ログイン時刻と一時ログイン鍵を独立して処理し、それぞれ削除確認を行います。

暗号化データの通常保存時も、保存前の暗号化データと旧データを保持し、新データの読み戻し確認・旧データ削除確認に失敗した場合は、変更前の状態へ差し戻して再確認します。
